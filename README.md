Данный проект реализует алгоритм MMM (Method of Means and Medians) - Метод Медианного Разбиения.
Для начала работы программы: python run_tests.py
По умолчанию run_tests.py запускает все JSON файлы из папки tests
Чтобы запустить отдельный файл нужно добавить флаг --case
Например python run_tests.py --case test_easy.json
Результаты работы находятся в папке results 
При новом прогоне старые результаты стираются (требуется обсуждение этого момента)
test_generator.py создаёт по умолчанию 4 файла входных данных (легкий, средний, тяжёлый и самый сложный) в папке tests
